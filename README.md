# React Native Lifecycle Demo

A comprehensive learning project demonstrating React Native component lifecycle methods and hooks.

## 🎯 Features

- 📱 **Class Component Lifecycle**
  - Constructor
  - componentDidMount
  - shouldComponentUpdate
  - componentDidUpdate
  - componentWillUnmount

- ⚛️ **Functional Component with Hooks**
  - useState Hook
  - useEffect Hook (Mount, Update, Cleanup)
  - useRef Hook

- 🎯 **Interactive Examples**
  - Counter with state management
  - Async data fetching simulation
  - Lifecycle events logging
  - Render count tracking

npx @react-native-community/cli@latest init LifecyclePoC
